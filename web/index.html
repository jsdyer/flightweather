A forecast needs a timestamp.
Keep the chronology
Issue time is when a forecast was published. Valid time is when it applies. Capture time is when this tool saved it. The default comparison requires a forecast saved before the observation occurred. Reconstructed comparisons use issue time and are labelled separately.
Read the alternatives
TEMPO and PROB periods are shown as conditional alternatives, never substituted for the prevailing forecast. BECMG periods and their aftermath are excluded from deterministic pairing until the next FM period. No overall forecast grade is assigned.
Keep the gaps
A missing report is not clear weather. Visibility such as “6+” is a lower bound, not an exact value. No reported ceiling is not zero feet. Wind directions are true degrees; speeds are knots. All times here use UTC.
Source: NOAA / NWS Aviation Weather Center API. Reports are collected by GitHub Actions, because the provider does not permit cross-origin browser API requests. Filters and imported receipts stay in this tab. A failed collection preserves the last good record.
